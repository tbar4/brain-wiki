# Spawned Threads May not finish executing before the main thread


```rust
use std::thread;

fn main() {
	thread::spawn(f);
	thread::spawn(f);
	
	println!("Hello from the main thread");
}

fn f() {
	println!("Hello from another thread");
	
	let id = thread::current().id();
	
	println!("This is the thread id: {id:?}");
}
```

The results from above may vary as the spawned threads may not finish running before the main thread finishes and returns the execution. In order to *wait* for the threads we need to join them using handles[^1].

```rust
use std::thread;

fn main() {
	let t1 = thread::spawn(f);
	let t2 = thread::spawn(f);
	
	println!("Hello from the main thread");
	
	// The `join()` method waits until the thread has finished executing
	// and then returns a `std::thread::Result`
	t1.join().unwrap();
	t2.join().unwrap();
}

fn f() {
	println!("Hello from another thread");
	
	let id = thread::current().id();
	
	println!("This is the thread id: {id:?}");
}
```
