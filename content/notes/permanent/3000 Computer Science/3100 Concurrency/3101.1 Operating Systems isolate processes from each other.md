# Operating Systems isolate processes from each other
A process cannot normally access the memory or resources of another process, or communicate with it in anyway without asking the operating system's kernel. A program can spawn *threads of execution* as part of the same process, which can share resources like memory and communication[^1].

Every program in Rust starts with one thread, which is the main thread. From here, the main function can spawn more threads using the `std::thread::spawn` function.
