# Open source efforts improve military tech


previous note: [[0106.4 Innovation in AI & Big Data]]
related note(s):
- 
---
Open source software includes the ability of the military by using and learning from open source communities. Buzz is an example, as it is an open source swarm software designed to control robot swarms. This type of technology can be used to overwhelm enemy positions and systems with cheap drones. Even Open source software as mundane as analytics software could be used to great advantage by a military to assess targets and risks.
