# Single Component Reliability in Software Bus

A major vulnerability in satellite systems that are using a Software Bus for communication is the fact that if the Software Bus goes down, then the whole satellite goes down. This is also true for the command ingestion module, if that goes down, communications via uplink are unable to be received and the whole satellite is lost (Schalk et al., 2022, p. 353).
