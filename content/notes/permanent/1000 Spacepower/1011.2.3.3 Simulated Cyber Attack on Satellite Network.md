# Simulated Cyber Attack on Satellite Network

Schalk, Brodnik, and Brown were able to simulate 4 different exploits on [[1010.1.1 NASA core Flight System (cFS)|NASA cFS]] via [[1010.3 OpenSatKit|OpenSatKit]];  a [[1011.2.3.3.1 No-Op Vulnerability|Replay Attack]], a cyber based [[1011.2.3.3.2 DoS Attack|DoS Satellite attack]], an [[1011.2.3.3.3 Exploit Command|exploit command that deletes the ingest module]], and an systematic [[1011.2.3.3.4 Brute Force Command|brute force exploit]] that sends cFS commands to delete an application of any name (Schalk et al., 2022, p. 353).
