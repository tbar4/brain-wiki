# Satellite Software Bus


previous note: [[1010 Satellite Software]]
related note(s):
- 

When the satellite starts a number of applications automatically subscribe to the Software Busand start to receive messages. The ground station send a command to the satellite, which then receives it via its communication application and sends the message to the Software Bus. Once all applications that are supposed to receive the message receive it, the command executes. Reverse the process to send data back to the Ground Station (Schalk et al., 2022, p. 353).
