# Space Packet Protocol

The SPP was developed by the CCSDS (Consultative Committee for Space Data Systems) and was built as a reliable communication standard for satellites and is widely adopted by the industry. It does not provide any security function, but security functions can be implemented at the SDLS (Space Data Link Security) protocols at the network layer. SDLS *should* be implemented if you are aiming for secure communications (as everyone should) (Schalk et al., 2022, p. 351). This still requires cryptographic keys on both ends of the ground station and satellite to be secure.
