# The CODE Method

The CODE method is a 4 part process to help build your second brain[3]. The steps are:
- **Capture** - Keep what resonates
- **Organize** - Save for actionability
- **Distill** - Find the essence
- **Express** - Show your work

When taking notes, it is extremely important that you [[4001.2.1 Write Notes in Your Own Words|write them in your own words]][3]. Make sure that you only [[4001.2.2 Only Capture Ideas That Resonate with You|capture notes that actually resonate with you]][3].You will also want to develop the 3 important habits which are [[4001.2.3 3 Important Note Taking Habits|utilize checklists, do weekly and monthly reviews, and to build *noticing* as a habit]][5].

Be sure that you are [[4001.2.4 Organize your notes for action|organizing your notes for action]][11]. A good way to ensure that you do this is by creating an [[4001.2.5 Create an Archipelago of Ideas|archipelago of ideas]][14].
